# TVC-Programok

Kész, futtatható programok a **Videoton TV-Computerre** (TVC). Minden program a saját mappájában van, mindennel, ami a
futtatásához kell (.CAS, lemezkép, adatfájlok), és egy leírással a használatáról.

| Program | Mi ez | Letöltés |
|---|---|---|
| [SIDSoftEMU](SIDSoftEMU/) | C64-es SID-zenék lejátszása a TVC saját hangján, SID-kártya nélkül | [SIDSoftEMU 1.1](https://github.com/LaM3rzLG/TVC-Programok/releases/tag/sidsoftemu-1.1) |
| [SID2TVC Converter](SID2TVC_Converter/) | PC-s átalakító (Windows, macOS, Linux): `.sid` → SIDSoftEMU-dal (`.STC`) vagy BIN a unithoz | [sid2tvc 1.4](https://github.com/LaM3rzLG/TVC-Programok/releases/tag/sid2tvc-1.4) |
| [SID2TVC TRSE Unit](SID2TVC_TRSE_Unit/) | TRSE-unit: C64-es SID-zene háttérzenének saját programba, játékba | [SID2TVC TRSE Unit 1.0](https://github.com/LaM3rzLG/TVC-Programok/releases/tag/sid2tvc-trse-unit-1.0) |

**Letöltés:** a táblázat „Letöltés” oszlopában egy ZIP-ben megvan minden, ami a programhoz kell. A fájlokat a
program mappájából egyesével is le lehet tölteni.
